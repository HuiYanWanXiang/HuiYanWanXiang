阻尼振动

在现实世界中，由于摩擦或阻力，振动系统的能量会逐渐耗散，振幅随时间衰减，这就是阻尼振动。

m d²x/dt² + b dx/dt + kx = 0

其中：

  • m：振子质量 (kg)
  • b：阻尼系数 (Ns/m)，决定能量耗散快慢
  • k：弹簧劲度系数 (N/m)
  • x：位移 (m)

三种阻尼状态：

  • 欠阻尼 (b² < 4mk)：系统围绕平衡位置进行振幅衰减的振动。
  • 临界阻尼 (b² = 4mk)：系统以最快速度回到平衡位置且不超调。
  • 过阻尼 (b² > 4mk)：系统不发生振荡，缓慢回到平衡位置。

受迫振动与共振

当振动系统受到周期性外力驱动时，称为受迫振动。其运动方程变为：

m d²x/dt² + b dx/dt + kx = F₀ cos(ωₐ t)

其中：

  • F₀：驱动力幅值
  • ωₐ：驱动力的角频率

系统最终会以驱动频率 ωₐ 振动，其稳态振幅为：

A = F₀ / √((k - mωₐ²)² + (b ωₐ)²)

共振现象：当驱动频率 ωₐ 接近系统的固有频率 ω₀ = √(k/m) 时，振幅 A 达到最大值。阻尼系数 b 越小，共振峰越尖锐。

共振在工程和生活中广泛存在，如桥梁设计、收音机调台、MRI设备等。
