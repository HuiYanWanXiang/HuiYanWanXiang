极限的直观理解

从“逼近”与“误差控制”两个角度理解极限：函数值越来越接近某个数，而不是一定等于它。

什么是极限

极限描述的是“趋近过程”，并不要求在目标点函数一定有定义。

lim x→a f(x) = L

意思是：只要 x 足够接近 a（但不一定等于 a），f(x) 就能足够接近 L。

ε-δ 语言

对于任意 ε>0，都存在 δ>0，使得：

0 < |x-a| < δ ⇒ |f(x)-L| < ε

这是把“足够接近”写成严格数学条件。
