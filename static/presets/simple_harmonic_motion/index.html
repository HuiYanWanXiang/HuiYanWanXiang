简谐运动方程

简谐运动是最基本的周期性运动，物体受到与位移成正比且方向相反的回复力：

F = −kx   →   d²x/dt² = −ω²x

其解析解为：

x(t) = A cos(ωt + φ)

对时间求导得速度和加速度：

  • 速度：v(t) = −Aω sin(ωt + φ)
  • 加速度：a(t) = −Aω² cos(ωt + φ) = −ω²x

其中 A 为振幅，ω = √(k/m) 为角频率，φ 为初相位。

特征量与能量守恒

  • 周期：T = 2π/ω = 2π√(m/k)
  • 频率：f = 1/T = ω/(2π)
  • 最大速度：v_max = Aω（在平衡位置）
  • 最大加速度：a_max = Aω²（在最大位移处）

能量守恒：

E = ½mv² + ½kx² = ½kA² = 常数

动能与势能之间相互转化，总机械能守恒；相图轨迹为椭圆，正是能量守恒的体现。

相位关系：速度相位超前位移 π/2，加速度与位移反相（相差 π）。
