光的干涉与双缝实验

两列频率相同、相位差恒定的相干光波叠加时，某些位置振幅加强（相长干涉），另一些位置振幅减弱（相消干涉），形成稳定的干涉图样。

相长干涉（亮纹）条件：

δ = d sin θ ≈ dy/L = mλ，m = 0, ±1, ±2, …

相消干涉（暗纹）条件：

δ = (m + 1/2)λ，m = 0, ±1, ±2, …

其中 δ 为两缝至屏上某点的路程差，d 为缝间距，y 为该点到中心的距离，L 为缝到屏的距离。

条纹间距公式与意义

相邻亮纹（或暗纹）的间距为：

Δy = λL / d

其中：

  • λ：光的波长（m）
  • L：双缝到屏幕的距离（m）
  • d：两缝间距（m）

规律：

  • 波长越长 → 条纹越宽
  • 缝间距越大 → 条纹越窄
  • 屏距越远 → 条纹越宽

应用：双缝实验首次证明了光的波动性（托马斯·杨，1801年），是物理史上最重要的实验之一。
