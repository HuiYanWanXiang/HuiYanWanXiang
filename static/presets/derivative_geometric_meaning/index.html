导数的定义

导数描述函数值随自变量的瞬时变化率。函数 f(x) 在点 x₀ 处的导数定义为：

f′(x₀) = limΔx→0 [f(x₀+Δx) − f(x₀)] / Δx

其中 [f(x₀+Δx)−f(x₀)]/Δx 是函数在区间 [x₀, x₀+Δx] 上的平均变化率（即割线斜率）。

当 Δx 趋向 0 时，割线的极限位置就是切线，斜率极限值即为导数。

几何意义与常用公式

几何意义：f′(x₀) 等于曲线 y=f(x) 在点 (x₀, f(x₀)) 处切线的斜率。

过切点的切线方程为：

y − f(x₀) = f′(x₀) · (x − x₀)

常用导数公式：

  • (xⁿ)′ = nxⁿ⁻¹
  • (sin x)′ = cos x
  • (cos x)′ = −sin x
  • (eˣ)′ = eˣ
  • (ln x)′ = 1/x

物理应用：位移对时间求导得速度，速度对时间求导得加速度。
