标准形式

y = ax² + bx + c (a≠0)
  • a 决定开口方向和宽窄。
  • b 决定对称轴位置。
  • c 是 y 轴截距。

顶点与判别式

x_v = -b/(2a), y_v = f(x_v)
Δ = b² - 4ac
  • Δ > 0: 两个实根
  • Δ = 0: 一个实根（重根）
  • Δ < 0: 无实根
