Animation Plan: Conic Sections and Apollonius Circle Motion Trajectory

Concept Breakdown:
- Visualize the Apollonius circle definition: set of points where distance ratio to two fixed foci is constant.
- Show how this circle relates to conic sections (ellipse, parabola, hyperbola) through varying ratio.
- Animate a point moving along the Apollonius circle while tracing its trajectory.
- Demonstrate parameter changes affecting circle size and position relative to foci.

Scene Structure (12 seconds total):

Scene 1: Setup and Definition (3.0s)
- Start with two fixed points F1 (left) and F2 (right) labeled, 4 units apart horizontally.
- Display equation: |PF1|/|PF2| = k (constant ratio).
- Draw coordinate axes faintly in background.
- Add text: "Apollonius Circle: Points where distance ratio to two foci is constant."

Scene 2: Circle Formation (3.0s)
- Animate circle appearing with center on line F1F2.
- Show radius calculation: r = |k·d|/|k²−1| where d = F1F2 distance.
- Label circle as "Apollonius Circle" with current k value.
- Keep circle fully inside frame with radius ≤ 3 units.

Scene 3: Point Motion and Tracing (4.0s)
- Introduce point P on circle.
- Animate P moving counterclockwise along full circle.
- Trace P's path (the circle itself) as it moves.
- Show distance lines PF1 and PF2 with labels updating in real time.
- Display ratio |PF1|/|PF2| updating numerically.

Scene 4: Parameter Variation (2.0s)
- Animate k changing from 0.5 to 2.0.
- Show circle center and radius adjusting smoothly.
- End with k=1 case (perpendicular bisector as degenerate circle).
- Final text: "Apollonius Circles generate conic sections when k varies."

Layout Constraints:
- All objects must stay within 7x4 unit frame.
- Foci positioned at (-2,0) and (2,0) initially.
- Text placed top/bottom edges, never overlapping main objects.
- Equations fixed in corners, not drifting.
- Circle radius limited to prevent clipping.
- Distance lines fade when too long to avoid clutter.

Timing Notes:
- Scene transitions: 0.5s crossfade.
- Point P completes exactly one revolution in 3.5s.
- Ratio updates every 0.2s during motion.
- Parameter change animation: smooth 1.5s transition.

Key Objects:
- Foci F1, F2 (red dots).
- Apollonius circle (blue, dashed).
- Moving point P (yellow, glowing).
- Distance lines (gray, thin).
- Ratio display (top right corner).
- Parameter k control (slider visual, bottom left).

Equations:
- Main definition: |PF1|/|PF2| = k
- Circle center: ((k²x₂−x₁)/(k²−1), 0) if k≠1
- Circle radius: k·|x₂−x₁|/|k²−1|
- Distance formula: √[(x−xᵢ)² + y²]

This plan ensures all elements remain visible, properly spaced, and mathematically accurate throughout the 12-second animation.
