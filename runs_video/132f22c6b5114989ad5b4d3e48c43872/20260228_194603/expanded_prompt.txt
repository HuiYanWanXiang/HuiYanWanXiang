**Animation Plan: Pythagorean Theorem**

**Concept Breakdown:**
1. Introduce right triangle with sides a, b, c (hypotenuse)
2. Show squares constructed on each side
3. Demonstrate area equivalence: a² + b² = c²
4. Visual proof by rearrangement of square areas

**Scene Structure (Total: ~12 seconds):**

**Scene 1: Triangle Introduction (3 seconds)**
- Start with blank screen
- Animate drawing of right triangle (thick lines)
- Label vertices: A, B, C (C at right angle)
- Label sides: a (vertical), b (horizontal), c (hypotenuse)
- Add right angle symbol at C
- **Layout:** Triangle centered, occupying ~40% of frame height

**Scene 2: Square Construction (3 seconds)**
- Construct squares on each side:
  - Square with side a (attached to side a)
  - Square with side b (attached to side b)
  - Square with side c (attached to hypotenuse)
- Color squares differently (light blue, light green, light yellow)
- Label areas: a², b², c²
- **Layout:** Squares positioned outward from triangle, all fully visible within frame

**Scene 3: Area Comparison (3 seconds)**
- Highlight a² and b² squares with glow effect
- Show equation: a² + b²
- Animate equals sign appearing
- Highlight c² square with glow effect
- Show complete equation: a² + b² = c²
- **Layout:** Equation positioned below triangle, centered, fixed position

**Scene 4: Visual Proof (3 seconds)**
- Dissolve original squares
- Show 4 copies of original triangle
- Arrange triangles to form larger square with side (a+b)
- Show inner square with area c²
- Rearrange same triangles to show squares a² and b²
- Return to equation: a² + b² = c²
- **Layout:** Rearrangement occurs in same central area, all elements bounded

**Timing Notes:**
- Each scene: ~3 seconds
- Smooth transitions between scenes
- Pause briefly on final equation

**Key Objects & Constraints:**
- Triangle: Fixed size, centered
- Squares: Proportional to sides, no overlap
- Labels: Fixed positions, consistent font size
- Equations: Always visible when shown, no drifting
- All elements remain within safe frame boundaries
- No overlapping text during animations
- Final equation remains on screen for 2 seconds
